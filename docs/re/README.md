# Symbol map of Game.exe 1.09

A map of what we know about Game.exe (MD5 `7dc4fda2f6b7e8a6b70e846686a81938`): function starts with names,
classes (vtables), the developers' source files, the unit/building type struct and the handlers of script
commands and rules.txt keys. **Only addresses, names and our own notes** - no game code and no game text.
Everything is generated by `tools/re/symbols.py` from your own Game.exe, so it can be rebuilt any time.

| File | Content |
|---|---|
| `game109-symbols.tsv` | address, kind (func/label/vtable), name, source of the name, source file, note |
| `game109-modules.tsv` | the game's source files (from paths the game still contains) with their address range |
| `game109-unittype.tsv` | unit/building type struct: offset, type, rules.txt key |
| `game109.r2` | the same names for radare2: `r2 -i docs/re/game109.r2 Game.exe` |
| `coverage.txt` | how much of the program has a name |

Rebuild: `pip install pefile capstone` and `python3 tools/re/symbols.py Game.exe docs/re`
(`--with-strings` adds the game's log texts to the notes - local use only, never commit).

Tools:
- `tools/re/apply_symbols_ghidra.py`: Ghidra script that applies the TSV (names, labels, comments).
- `tools/re/decompile.py`: C-like pseudo code of one function with angr (`pip install angr`). Local analysis
  only: the output is derived from the game's code and must not be committed or published.
- `tools/re/re_tools.py`: small helpers (strings, cross references, disassembly).

How names are found (column "source"): `manual` = verified by hand (docs/reverse-engineering.md);
`logstr` = named after the function's own log message (e.g. `CUnitObject::Update, Invalid state`);
`vtable` = class known from another entry of its vtable or from the constructor's source file, unnamed
entries become `Class::vf_<slot>`, entries shared by several classes `Base::vf_...`/`CUnitObject::vf_...`;
`module` = only the source file is known; `script`/`rules` = labels of the handlers of script commands and
rules.txt keys inside the big switch functions. Automatic names are hints - check before relying on one.

Add new findings to `MANUAL` in `tools/re/symbols.py` (and to docs/reverse-engineering.md), then rebuild.
